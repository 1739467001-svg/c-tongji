# 自适应毕设共创专家团 · Adaptive Thesis Co-Creation Expert Panel

> **一个人做毕设,一支会自适应的专家团撑腰。**
>
> 参赛作品 · TT设计学院 SKILL 创新应用大赛(同济大学设计创意学院 × 腾讯云)
> 参赛方向:**TT设计·共创**(小组作业神器 / 多人协同)

---

## 一、痛点:毕设最难的不是没想法,是没人陪你想

设计学生做毕设 / 大作业 / 竞赛,最大的困境是**一个人闷头做,缺少多视角的及时反馈**:

- 导师太忙,一周见不上一次,反馈不及时;
- 同学各做各的,帮不上专业的忙;
- 自己看自己的方案,永远看不出盲区;
- 等到中期评审 / 答辩,才被评委批得体无完肤——为时已晚。

**好方案是"吵"出来的**。真正让项目变强的,是不同立场的人围着它较劲。可惜独自做毕设的学生,恰恰没有这张"圆桌"。

## 二、方案:把"一群专家围着你开会"产品化

本 SKILL 召集 **7 位性格鲜明的 AI 专家角色**,组成一张专属于你的评审圆桌:

| 角色 | 视角 |
|---|---|
| 🎙️ 主持人 同学姐 | 组织、串场、综合行动清单 |
| 🎓 学术导师 严教授 | 研究问题、创新点、方法论 |
| 🧭 体验设计专家 林教练 | 真实用户、场景、可用性 |
| 🤖 AI技术专家 算博士 | 技术可行性、"自适应"真伪 |
| ⚖️ 伦理与社会影响官 审官 | 偏见、隐私、社会风险 |
| 💼 落地与价值专家 周合伙人 | 价值主张、差异化、可落地 |
| 🔥 毒舌评委 评委 X | 唱反调、模拟答辩最难一问 |

他们会**多视角点评 → 互相辩论分歧 → 综合出带优先级的行动清单**,还能切换成「答辩模拟」模式提前帮你扛住拷问。

## 三、核心创新:**自适应**(本作品的灵魂)

普通的"AI 帮我改毕设"是一个 AI 给一段笼统建议。本作品不同——它**会自适应**:

1. **按阶段自适应**:选题期重点是"值不值得做",答辩期重点是"扛不扛得住问"。出场专家、点评侧重完全不同。
2. **按专业自适应**:做 AI / 自适应系统类项目,AI技术专家 + 伦理官必到场;做文创类则换体验 + 落地专家挑大梁。
3. **按火力自适应**:🌱 鼓励 ↔ ⚖️ 标准 ↔ 🔥 答辩拷问,一句话切换力度。

> 🎯 **设计巧思**:本作品作者专业为「AI 人工智能自适应系统」。我们让作品本身成为一个"自适应系统"的范例——**形式即内容**:它根据用户状态(阶段 / 专业 / 信心)动态调整专家阵容与反馈策略。每轮开场都会"公示阵容与理由",让自适应**看得见**。

完整路由逻辑见 [`workflow.md` 自适应路由表](.claude/skills/bishe-expert-panel/workflow.md)。

## 四、怎么用(5 步工作流)

1. **诊断**:3 个问题定位你的项目、阶段、专业与想要的火力。
2. **自适应组团**:按路由表选出本轮 3–5 位专家,并公示理由。
3. **多视角评审**:每位专家给「亮点 / 致命问题 / 关键追问 / 立刻可做」四段卡片。
4. **辩论与综合**:专家就分歧交锋,主持人综合成 P0/P1/P2 行动清单。
5. **收尾**:进入答辩模拟 / 推进下一阶段 / 调火力再来一轮。

👉 **完整实战演示见 [`examples/demo-session.md`](examples/demo-session.md)**(一次真实的"AI 自适应学习陪练"毕设评审全过程)。

## 五、技术实现:无需代码,纯自然语言定义

本作品是一个 **Claude Code / Agent Skill**,完全用自然语言(Markdown)定义,**零代码**,契合大赛"无需代码基础就能打造专属 AI 设计工具"的理念。

```
.claude/skills/bishe-expert-panel/
├── SKILL.md                      # 主控:工作流与执行指令
├── personas.md                   # 7 位专家的完整人设
├── workflow.md                   # 自适应路由表(核心)
└── templates/
    ├── review-report.md          # 专家评审卡片格式
    └── defense-qa.md             # 答辩模拟脚本
```

采用 **渐进式披露**:主控 `SKILL.md` 精简,细节按需加载,既高效又易维护——这本身就是一种好的"系统设计"。

## 六、上架与迁移(适配技能广场 / Ardot)

作品的核心 IP 是**专家人设 + 自适应路由 + 评审/答辩模板**这套提示词设计,与平台无关,可平滑迁移:

- **腾讯元器 / Ardot 智能体**:把 `personas.md` + `workflow.md` 填入角色设定与知识库即可。
- **任意支持自定义指令的 Agent**:`SKILL.md` 即系统提示词主体。
- **Claude Code**:已是可直接运行的 Skill,放进 `.claude/skills/` 即可被调用。

## 七、为什么它能打(对齐大赛评分)

- **可落地、可演示**:不是 PPT 构思,是当场能跑、能交互的真实工具。
- **强原创、有记忆点**:"会自适应的专家团" + "形式即内容"的叙事,容易出圈传播。
- **真实痛点**:直击每个毕设学生的刚需,评委本身大多当过被学生求反馈的导师,共鸣强。
- **可持续**:做完毕设还能用于竞赛、求职作品集打磨——长期价值。
